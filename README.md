# Company Name Cleaner

A tiny, single-file tool that cleans up messy company names for outreach — built for anyone in BD, sales, or email marketing who's ever had to prep a lead list for a mail-merge or spintax personalization.

**[Try the live version →](https://sshnox.github.io/company-name-cleaner/)** (once GitHub Pages is enabled — see below)

No install. No signup. No server. It runs entirely in your browser, and nothing you paste ever leaves your machine.

## Why this exists

If you've ever pulled a lead list from Apollo, LinkedIn Sales Nav, or a CRM export, you've seen this:

```
Areti Group | B Corp™
Paragon Alpha - Hedge Fund Talent Business
The Staffing Agency, LLC
COLLIER LEGAL SEARCH
HYRE HARPER Co.
```

Drop any of those straight into a `{{companyName}}` merge field and your email reads like it was generated by a scraper — because it was. This tool cleans all of it into names you can actually use in a sentence:

```
Areti Group
Paragon Alpha
The Staffing Agency
Collier Legal Search
Hyre Harper
```

## Features

- **Paste or drag-and-drop** — paste a list directly, or drop a `.csv` file onto the page
- **9-stage cleaning pipeline** — visually shows each step as it runs
- **Live preview table** — see every original name next to its cleaned version, with changes flagged
- **One-click CSV export** — download a two-column CSV (original + cleaned) ready for your CRM or outreach tool
- **100% client-side** — no backend, no API calls, no data leaves your browser
- **Zero dependencies** — a single HTML file, works offline once downloaded

## What it cleans

| Problem | Example | Result |
|---|---|---|
| Legal suffixes | `Cyperus Group LLC` | `Cyperus Group` |
| Taglines after a pipe | `WorQFlow \| Trusted D365 Talent & Solutions` | `WorQFlow` |
| Taglines after a dash | `Paragon Alpha - Hedge Fund Talent Business` | `Paragon Alpha` |
| Colon descriptors | `LAPS: Life After Professional Sport` | `LAPS` |
| Parenthetical notes | `VRS Recruitment (US)` | `VRS Recruitment` |
| Trademark / emoji symbols | `Areti Group \| B Corp™` | `Areti Group` |
| Trailing comma clauses | `Employment Resource Group, Inc. An EOS company` | `Employment Resource Group` |
| ALL-CAPS "shouting" names | `COLLIER LEGAL SEARCH` | `Collier Legal Search` (acronyms like `GDL`, `HCT`, `MEP` stay uppercase) |
| Franchise/location tags | `Express Employment Professionals - Tacoma, WA` | `Express Employment Professionals` |

## Usage

1. Download `index.html` (or clone this repo)
2. Open it in any browser — Chrome, Firefox, Safari, Edge
3. Paste your list of company names (one per line) or drop a CSV
4. Click **Clean names**
5. Review the preview, then click **Download cleaned CSV**

That's it. No build step, no `npm install`.

### Running locally from source

```bash
git clone https://github.com/sshnox/company-name-cleaner.git
cd company-name-cleaner
open index.html   # or just double-click the file
```

### Hosting your own copy

Since it's a static file, you can host it anywhere — GitHub Pages, Netlify, Vercel, or just email the HTML file to a teammate. To enable GitHub Pages on your fork:

1. Go to **Settings → Pages**
2. Set source to the `main` branch, root folder
3. Your tool will be live at `https://<your-username>.github.io/company-name-cleaner/`

## How the cleaning logic works

The pipeline runs each name through 9 steps, in order:

1. Strip content inside parentheses
2. Strip emojis and non-ASCII symbols (™, ®, etc.)
3. Cut at a pipe (`|`), keep the first segment
4. Cut at a colon followed by a space
5. Cut at a dash used as a separator (only when it has whitespace next to it — so hyphenated names like `AGRI-SEARCH` are left intact)
6. Strip legal suffixes (LLC, Inc, Ltd, Limited, Corp, PLC, GmbH, etc.) — run in a loop to catch stacked suffixes
7. Cut at the first remaining comma
8. Clean up stray punctuation and whitespace
9. Fix ALL-CAPS names: if the whole name is uppercase and has 2+ words, convert to Title Case — but keep short (≤3 letter) tokens uppercase, since those are usually acronyms (`GDL`, `HCT`, `MEP`), not shouting

A small override list handles the rare edge cases no general rule can safely resolve (e.g. keeping `"& Co."` intact, since that's a legitimate part of a firm's name rather than a suffix to strip).

## Known limitations

- It's rule-based, not AI — genuinely ambiguous names (e.g. is "Global Talent Partners Veterinary" a niche descriptor or part of the actual brand?) may need a manual check
- Very unusual formatting patterns not covered by the 9 rules may need a one-off fix — the code is short and readable, so patches are easy to add
- It doesn't deduplicate rows — if that's useful to you, it's a small addition (PRs welcome)
